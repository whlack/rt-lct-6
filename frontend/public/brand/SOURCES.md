# Брендовые ресурсы frontend

- `rt-logo.png` — горизонтальный логотип Ростелекома из официальных публичных материалов фирменного стиля. Изображение используется без перерисовки.
- `../fonts/RostelecomBasis-{Regular,Medium,Bold}.woff2` — локальные файлы шрифта из двух согласовываемых дизайн-прототипов команды.

Эти ресурсы не являются свободным UI-kit. Перед созданием публичного зеркала и конкурсным развёртыванием команда должна подтвердить право распространения шрифтов и актуальность брендовых файлов.
