## Команде LMS ИТ Школы Ростелекома

Тема: API-контракт и тестовые данные для интеграции LMS с CRM вузов

Для подготовки интеграции CRM вузов с LMS просим предоставить:

1. Описание доступных методов API, адресов тестового и рабочего окружений, способа авторизации и требований к доступу.
2. JSON-схемы запросов и ответов с обязательными и необязательными полями, типами, допустимыми значениями и примерами успешных ответов и ошибок.
3. Тестовые JSON-примеры для создания, изменения и отсутствия данных; примеры без реальных персональных данных.
4. Стабильные идентификаторы записей, правила изменения/удаления, порядок повторной передачи и способ определения обновлённых записей.
5. Ограничения частоты запросов, пагинацию, часовой пояс дат и контакт для уточнения маппинга полей CRM.

Просим также указать, какие данные LMS должны попадать в CRM и кто согласует их сопоставление с вузом, направлением, программой или продуктом и проектом. После получения материалов согласуем маппинг до разработки интеграции.

## Команде сайта на Laravel

Тема: API-контракт и тестовые данные для интеграции сайта с CRM вузов

Для подготовки интеграции сайта на Laravel с CRM вузов просим предоставить:

1. Описание методов API или событий передачи данных, адресов тестового и рабочего окружений, способа авторизации и требований к доступу.
2. JSON-схемы запросов и ответов с обязательными и необязательными полями, типами, допустимыми значениями и примерами успешных ответов и ошибок.
3. Тестовые JSON-примеры для новой, изменённой и пустой записи; примеры без реальных персональных данных.
4. Стабильные идентификаторы записей, правила изменения/удаления, повторной передачи и определения обновлённых записей.
5. Ограничения частоты запросов, пагинацию при наличии, часовой пояс дат и контакт для уточнения маппинга полей CRM.

Просим указать, какие данные сайта должны попадать в CRM и по каким признакам они связываются с вузом или проектом. Пример `Данные оплат.json` из исходных материалов считаем только образцом структуры, не утверждённым контрактом; просим отдельно подтвердить фактические поля и их смысл.
