# Базовый шаблон импорта каталогов

Шаблон [catalog-import.xlsx](./templates/catalog-import.xlsx) — одна книга XLSX с четырьмя листами. Первая строка каждого листа содержит заголовки без дополнительных строк над ними. Строки ниже предназначены для записей каталога; пустые строки игнорируются. Листы можно загружать вместе, в порядке их расположения в книге.

| Лист                   | Колонки в порядке шаблона | Обязательные колонки   | Ключ повторной загрузки |
| ---------------------- | ------------------------- | ---------------------- | ----------------------- |
| `Вузы`                 | `Название вуза`           | `Название вуза`        | Название вуза           |
| `Направления`          | `Название направления`    | `Название направления` | Название направления    |
| `Программы и продукты` | `Тип`, `Название`         | Обе                    | Тип и название вместе   |
| `Сотрудники`           | `Email`, `ФИО`            | Обе                    | Email                   |

В колонке `Тип` допустимы только `Программа` и `Продукт`. Программа означает учебные материалы и практику по направлению, продукт — ПО для обучения. Связь с конкретным направлением задаётся при создании проекта, а не в этом базовом шаблоне.

## Сопоставление и ошибки

- Перед сравнением убрать пробелы по краям и привести последовательности пробелов внутри названий к одному пробелу; сравнение названий, типа и email выполнять без учёта регистра. Исходное написание значения из последней загружаемой строки сохранять для отображения.
- Если ключ найден однозначно, обновить существующую запись из непустых колонок шаблона, а не создавать новую. Если ключа нет, создать запись, кроме листа `Сотрудники`.
- Для `Сотрудники` найти существующую учётную запись Keycloak по email и связать её с локальной записью сотрудника; `ФИО` обновляет только отображаемое имя в CRM. Импорт не создаёт и не изменяет учётные записи Keycloak. Если учётная запись не найдена, строка получает ошибку.
- Если после нормализации одному ключу соответствуют несколько существующих записей или в книге есть повтор ключа с различающимися значениями, строка получает ошибку «Неоднозначное совпадение: укажите уникальное название или email и повторите загрузку». Совпадающие полностью повторные строки обрабатываются один раз.
- Для строки без обязательного значения сообщать лист, номер строки и имя колонки. Строки с ошибками не записывать; результат загрузки должен перечислять созданные, обновлённые, пропущенные и ошибочные строки.

Это базовый шаблон для этапа 0. Детальный маппинг приложенных `Вендоры.xlsx` и `Загрузка пользователей.xlsx`, а также импорт контактов вузов, в него не входят. Реализация загрузки и актуализации каталогов запланирована на этап 2.
